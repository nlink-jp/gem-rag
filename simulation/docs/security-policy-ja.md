# セキュリティポリシー

## 認証

すべてのAPIアクセスにはApplication Default Credentials（ADC）が必要です。
サービスアカウントには最小限のIAMロールを付与します。
トークンのローテーションは90日ごとに強制されます。

## インシデント対応

セキュリティインシデントが検出された場合:
1. SOCチームが15分以内にトリアージを開始する
2. インシデントの深刻度がHIGHまたはCRITICALの場合、CSIRTにエスカレーションする
3. インシデントコマンダーが封じ込めと修復を調整する
4. インシデント後のレビューを5営業日以内に実施する

## データ分類

| レベル | 説明 | 例 |
|--------|------|-----|
| 公開 | 制限なし | マーケティング資料 |
| 社内 | 全社アクセス可 | 社内Wikiページ |
| 機密 | 知る必要がある者のみ | 顧客PII、財務データ |
| 極秘 | 指名された個人のみ | 暗号鍵、監査ログ |

## アクセス制御

すべてのシステムでロールベースアクセス制御（RBAC）が適用されています。
特権アクセスにはMFAが必要であり、監査証跡にログが記録されます。
四半期ごとのアクセスレビューは、機密および極秘リソースに対して必須です。
