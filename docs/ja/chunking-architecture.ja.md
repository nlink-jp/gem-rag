# チャンキングアーキテクチャ

gem-rag は日英混在の Markdown ドキュメントに最適化された、
見出し認識型の多段チャンキング方式を使用します。

## パイプライン

```
Raw Markdown
    │
    ├─ normalize()          Unicode NFKC, 全角→半角, 制御文字除去
    │
    ├─ split_by_headings()  # 見出しで分割、階層を追跡
    │   │
    │   └─ 各セクション:
    │       │
    │       ├─ tokens ≤ chunk_size → 単一チャンク
    │       │
    │       └─ tokens > chunk_size:
    │           │
    │           ├─ atomize()
    │           │   ├─ split_paragraphs()    空行で分割
    │           │   └─ split_sentences()     JP: 。．！？  EN: .!?
    │           │
    │           └─ オーバーラップ付きパッキング
    │
    ├─ strip_markdown()     embedding 前にフォーマット除去
    │
    └─ embed()              Gemini text-embedding-005
```

## テキスト正規化

チャンキング前に一貫した分割を保証するために適用:

| ステップ | 操作 | 例 |
|----------|------|-----|
| 1 | Unicode NFKC | `Ｈｅｌｌｏ` → `Hello` |
| 2 | 全角スペース | `\u3000` → ASCII スペース |
| 3 | 改行コード | CRLF/CR → LF |
| 4 | 制御文字 | C0/C1 除去（LF, TAB は保持） |
| 5 | 連続スペース | `a    b` → `a b` |

## 見出し認識型分割

ドキュメントはまず Markdown 見出し境界（`#` 〜 `######`）で分割されます。

### 階層的見出しパス

各チャンクはドキュメント内の位置から**見出しパス**を継承します:

```markdown
# ガイド
## インストール
### Linux
apt-get install ...     ← heading_path: "ガイド > インストール > Linux"
### macOS
brew install ...        ← heading_path: "ガイド > インストール > macOS"
## 使い方
gem-rag ask "質問"      ← heading_path: "ガイド > 使い方"
```

### コードフェンス保護

フェンスドコードブロック内の見出しはセクション境界として扱われません。

## トークン推定

日英混在テキストのトークン推定（切り詰め回避のため保守的）:

| 文字種 | 推定値 | 根拠 |
|--------|--------|------|
| CJK（漢字、ひらがな、カタカナ） | 1文字 = 2トークン | CJK文字は通常2+のサブワードにトークン化 |
| ASCII/ラテン単語 | 1単語 = 1.3トークン | 英単語は平均約1.3サブワードトークン |

計算式: `(CJK文字数 × 2) + int(ASCII単語数 × 1.3 + 0.5)`

## 文境界検出

セクションが `chunk_size` を超えた場合の原子化:

1. **段落区切り**（空行）— 主要な分割単位
2. **日本語文末**: `。` `．` `！` `？`
3. **英語文末**: `.` `!` `?` + 空白

パターン: `[。．！？]+|[.!?]+(?:\s+|$)`

## オーバーラップ

チャンク出力後、末尾のブロックが次のチャンクのシードとして保持されます
（`chunk_overlap` トークンまで）。チャンク境界でのコンテキスト連続性を確保します。

## Markdown ストリッピング（embedding 前）

embedding 前にフォーマットを除去してベクトル空間のノイズを低減:

| パターン | 置換 |
|---------|------|
| `![alt](url)` | `alt` |
| `[text](url)` | `text` |
| `<html>` タグ | 除去 |
| `` ```code``` `` フェンス | 除去 |
| `` `inline` `` コード | `inline` |
| `## 見出し` マーカー | 除去 |

生の Markdown は `chunks.content` に表示用として格納。
ストリッピングは embedding 時のみ適用されます。

## デフォルトパラメータ

| パラメータ | デフォルト | 環境変数 |
|-----------|----------|---------|
| `chunk_size` | 512 トークン | `GEM_RAG_CHUNK_SIZE` |
| `chunk_overlap` | 64 トークン | `GEM_RAG_CHUNK_OVERLAP` |
