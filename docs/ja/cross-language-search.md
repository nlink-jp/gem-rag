# クロス言語検索

gem-rag は LLM によるクエリリライトを通じたクロス言語検索をサポートしています。
日本語の質問で英語のドキュメントを検出でき、その逆も可能です。

## 仕組み

```
ユーザークエリ（「認証の仕組みは？」）
    │
    ├─ 元のクエリ ──→ embed ──→ ベクトル検索 ──┐
    │                                           │
    ├─ Gemini リライト ──→ "JA: 認証の仕組みと方式"
    │                  ──→ "EN: Authentication mechanism and methods"
    │                      │                    │
    │                      ├─ embed JA ──→ 検索 ┤
    │                      └─ embed EN ──→ 検索 ┤
    │                                           │
    └───────────── マージ（チャンクID毎に最高スコア）┘
                              │
                        Top-K 結果
```

## クエリリライト

`query_rewrite` が有効（デフォルト: `true`）の場合、ユーザーのクエリが Gemini に
送信され、2つの書き換えが要求されます:

```
JA: <日本語に書き換えたクエリ>
EN: <英語に書き換えたクエリ>
```

リライターの処理:
1. 略語の展開と関連シノニムの追加
2. 疑問形から宣言形への変換（embedding マッチ精度向上）
3. 入力言語に関係なく JA/EN 両方のバリアントを生成

### 例

| 入力 | JA バリアント | EN バリアント |
|------|-------------|-------------|
| 「認証はどうなってる？」 | 「認証の仕組みと認証方式」 | "Authentication mechanism and methods" |
| "How does indexing work?" | 「インデックスの仕組みとチャンク処理」 | "Indexing mechanism and chunking process" |

## 並行実行

すべてのクエリバリアント（元 + JA + EN）は `ThreadPoolExecutor` で
**並行して** embedding・検索されます。レイテンシを最小化:

```
時間 ──→

元:    [embed]───[search]
JA:    [embed]───[search]
EN:    [embed]───[search]
                          ├── マージ ── 結果
```

## 結果のマージ

全検索結果を重複排除しながらマージ:

```python
# 各チャンクIDに対して最高スコアを保持
if chunk_id not in seen or new_score > seen[chunk_id].score:
    seen[chunk_id] = hit
```

JA と EN 両方のバリアントでマッチしたチャンクは、最高スコアが保持されます
（二重カウントにはなりません）。

## セキュリティ

リライタープロンプトは**衝突回避ノンスタグ XML** を使用:

```
<query-{nonce}>ユーザーの質問</query-{nonce}>
```

ノンスはクエリテキストに出現しないことが検証された 128 ビットの16進文字列です。
システムプロンプトはタグ内のコンテンツをデータとしてのみ扱うよう明示的に指示します。

## 設定

| パラメータ | デフォルト | 環境変数 |
|-----------|----------|---------|
| `query_rewrite` | `true` | `GEM_RAG_QUERY_REWRITE` |

無効化する場合（低レイテンシやオフライン時）:

```bash
GEM_RAG_QUERY_REWRITE=false gem-rag ask "質問"
```

## クロス言語検索が重要な理由

多言語コードベースとドキュメンテーション環境では:
- README.md は英語、README.ja.md は日本語で記述される
- コードコメントは言語が混在することが多い
- 会議記録（meeting-note 出力）は日本語、参照ドキュメントは英語ということがある

クエリリライトがなければ、日本語の質問は日本語チャンクのみにマッチし
（逆も同様）、他言語の関連コンテンツを見逃します。
クエリリライトにより、両方の言語空間が同時に検索されます。
